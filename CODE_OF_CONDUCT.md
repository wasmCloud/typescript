# Code of Conduct

This repository is part of the wasmCloud project
and follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Report possible violations to the wasmCloud org maintainers,
as described in wasmCloud's [governance](https://github.com/wasmCloud/wasmCloud/blob/main/GOVERNANCE.md#code-of-conduct),
or to the CNCF at <conduct@cncf.io>.
